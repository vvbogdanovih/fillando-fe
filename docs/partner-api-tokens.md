# API-токени партнерів

Сторінка `/admin/api-tokens` під загальним ADMIN guard, пункт «API-токени»
у sidebar. Backend окремо перевіряє JWT + ADMIN на всіх операціях.

GET `/admin/api-tokens` завантажує metadata. POST з `{name}` створює токен;
секрет тримається лише в React state, не потрапляє в React Query чи localStorage.
Поки одноразовий секрет відкритий, повторне створення заблоковане. Кнопки:
копіювання (з помилкою clipboard і ручним fallback), «Я зберіг токен — закрити».
Після навігації/перезавантаження секрет зникає. DELETE `/:id` відкликає токен
після підтвердження й оновлює список. Є loading, empty, error/retry стани.

Посилання на публічний Swagger: NEXT_PUBLIC_API_BASE_URL + `/partner-docs`.
Партнерський токен призначений для серверної інтеграції, не для авторизації
в адмінці. Розгорнути backend перед frontend.
